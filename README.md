# Kinnari Mishra — Academic Portfolio

A ready-to-deploy personal academic portfolio website.

## Structure
- `index.html` — the page markup
- `css/style.css` — all styling (light/dark theme, layout, components)
- `js/script.js` — navigation, theme toggle, animations, gallery lightbox, form handling
- `assets/images/` — profile photo and gallery photos
- `assets/docs/` — your CV and the 11 ATAL FDP certificates (linked as downloads)

## Deploy on GitHub Pages
1. Create a new GitHub repository (e.g. `kinnari-mishra-portfolio`).
2. Upload everything in this folder to the repository root (keep the folder structure).
3. In the repo, go to **Settings → Pages**, set the source to the `main` branch, root folder.
4. Your site will publish at `https://<your-username>.github.io/<repo-name>/`.

## Editing content
Open `index.html` in any text editor — each section is clearly commented
(`<!-- ================= SECTION NAME ================= -->`). Replace the
placeholder cards marked "Sample content — replace" (patents, grants, awards,
testimonials, and the extra social links) with your real details as they
become available.

## Notes
- The Download CV button and each FDP card link to files in `assets/docs/`.
- Google Scholar, ORCID, ResearchGate, GitHub, Scopus, YouTube, X, Facebook
  and Instagram icons are placeholders (`href="#"`) — add your profile URLs
  in the Contact section and footer to activate them. LinkedIn is already live.
- The contact form is front-end only; connect it to a form service (e.g.
  Formspree) or your own backend to actually receive messages.
